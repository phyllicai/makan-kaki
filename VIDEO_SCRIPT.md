# Demo video script (target 2:30, hard cap < 3:00)
Note: the Devpost page says videos are **not required**. Judges want a live demo. This script is optional, for social posts or if a finalist presentation is needed. Record in **live Qloo mode** (no MOCK badge).

| Time | Screen | Voice-over |
|---|---|---|
| 0:00–0:15 | Phone footage or still of a badminton court at night, then the app header | "It's 10:30pm, game over. Four sweaty kakis. One needs halal, one's vegetarian, one wants char kway teow, one wants a burger. Where do we makan?" |
| 0:15–0:35 | Setup panel: pick "SS2, Petaling Jaya", Thursday, 10:30pm, 3 km, $$ | "Makan Kaki is an agent with taste. Tell it where you played, when you finish, and how far you'll drive." |
| 0:35–0:55 | Fill the four players: cravings, a loved place, dietary ticks | "Each player adds what they're craving and places they already love. Those become Qloo taste signals: tags for cravings, real Qloo entities for loved places." |
| 0:55–1:10 | Click **Find our makan spot**, show the spinner, then results | "The agent asks Qloo Insights for spots near the court that fit the whole group's taste and are open on the day…" |
| 1:10–1:40 | Zoom into the #1 card: per-player bars, ✓ halal / ✓ vegetarian chips | "…then it asks Qloo again, once per player, to score every spot for every person. It picks the place with high average happiness where nobody is miserable. Here's how much each person matches, and the rules it checked." |
| 1:40–2:05 | Scroll the agent trace; highlight a REFLECT step (re-run with 1 km to trigger it) | "It's a real agent loop: plan, call tools, observe, reflect. If too few places fit, it widens the search and tries again. And if Qloo can't confirm halal or opening hours, it tells you to verify instead of guessing." |
| 2:05–2:20 | Mini map plus the 'Ruled out' list | "You can see where everything is and why the other places were ruled out." |
| 2:20–2:35 | README / architecture diagram, then the app | "Open source and MIT licensed. Qloo is the brain. An LLM is optional and only writes the pitch from verified facts. Makan Kaki: settle supper before the shuttlecock lands." |
